两条主线

  • 一条向上：智能的上界 — 跟踪 Scaling 曲线的演进路径（参数规模、训练算力、推理成本、能力边界），抓住一段时间内的经验规律与拐点信号；

LinkX Ideas

技术优先仍是第一优先级。

AGI 的拐点尚未到来，核心任务是在持续探索智能上限的同时，将模型已具备的能力在真实场景中有效激活与释放。

返回研究成果摘录

Scaling 仍是提升智能上限最高效的方法

更大规模数据（含合成/蒸馏数据）、更大参数、更多算力投入依然必要。真正决定智能上限的依然是文本——即使经过两年的多模态和端到端语音探索。

激活对齐与增强推理是释放能力的关键

  • 强化学习正逐步替代 SFT/CoT 成为对齐主流路径；Mid-training 和 Post-training 将使更多场景的快速对齐成为可能。
  • Agent 跨环境泛化与迁移仍是难题——最简路径是构造更多环境数据并针对不同环境做强化学习。
  • 模型下一步突破重点在记忆、在线学习与自我评估——context/RAG/参数分别对应短/中/长期记忆；自我评估机制可能孕育新的 scaling 范式。

应用层的策略

  • 应用层必须做得足够「薄」以适应模型能力快速演进。
  • 领域模型在 AGI 终局下很可能被基座模型覆盖，但当前窗口期仍有竞争机会。
  • 应围绕实际工作类型组织，而非 SaaS 时代的软件类别。

Onepage · Agent OS

从"响应式操作系统"到"Agent 行动系统"。

OpenClaw 现象的本质不是一款产品的成功，而是软件第一次从"被操作对象"变成了"行动主体"的范式迁移。

返回研究成果摘录

增长数据

OpenClaw 60 天突破 25 万 star，超越 React（24.3 万）和 Linux Kernel（21.8 万）成为 GitHub 历史上增长最快的软件项目。ClawHub 累计 2.6 万个 skills，Discord 成员 12 万。

中国应用落地速度首次超越美国：国产模型成本低 60–80%；多个地方政府推出扶持政策（合肥最高 1000 万元、无锡约 30 亿元产业基金）。

核心瓶颈

  • Token 成本：Agent 的 token 消耗量是传统聊天的 100–1000 倍；单次 agent loop 每次都重新加载历史消息+系统提示词+工具定义；"一夜之间因重试循环损失 120 美元"。
  • 鲁棒性：EvoClaw 测试显示最先进 Agent 在长序列任务平均成功率仅 38%，最复杂场景跌至 13.37%。
  • 安全：258 个历史漏洞，ClawHub 插件恶意代码占比 10.8%–26%。

范式转移

  • 竞争单位从「模型」变为「系统栈」：模型 + runtime + memory + toolchain + eval/observability + human interface。
  • 经济单位从「参数规模」转向「单位 Token 产出效率」——tokens per dollar, tokens per watt, 任务完成总成本。
  • 控制运行时者也可能控制训练，因为执行轨迹、反馈和强化学习循环在运行时内部生成。

行业分层视图

  • 模型 / 平台层（OpenAI / Anthropic）：开发者操作系统，控制模型 + Agent OS + 接口。Anthropic 全栈布局 MCP、Claude Code、经济指数与 Agent 自治；OpenAI 整合 Computer Use、Agent、工具与容器。竞争焦点是默认基础与默认协议。
  • 中间层：核心价值在于让 Agent 真正可用——设计 Agent 运行时执行环境。涵盖 Agent 编排、工作流 + 记忆 + 评测、评测与安全、可观测性（循环、Token 成本）。典型形态可能是 TaaS（如 Mechanize、Beam AI-Runtime）。
  • 应用层：可能诞生新形态——从 human-in-the-loop 工具演变为 human-on-the-loop 控制面板（cockpit / control panel）。Agent 价值越来越取决于安全执行环境、可组合技能/插件和工作流原生界面。

Onepage · 自进化

从 Scale 模型到 Scale 经验闭环。

AI 自进化是从"scale 参数×数据×算力"到"scale experience/feedback/experiments/discovery loop"的新 Scaling 方向。L3 是当前可验证拐点，L4 是分水岭。

返回研究成果摘录

自进化分级

  • L0：单点工具 → L1：单任务自修正 → L2：跨任务经验积累
  • L3：自动研究闭环（假设→实验→反馈→再假设）→ 当前可验证拐点
  • L4：能力回流闭环（经验进入下一代模型）→ 真正的分水岭
  • L5：开放式递归自我改进 → 高度不确定

反馈层级（V5→V0）

最强验证来自代码和数学（即时客观可重复）；最大挑战在 V0 开放式创新（幻觉式进步风险最高）。代码测试、数学证明、仿真和实验室实验是最可投资的早期环境。

专题研究 · 视频生成

物理真实 vs 可控性，路线分化已现。

两者都处于第一梯队，但技术路线和未来终局将分化——Vidu 偏物理一致性 & 世界模型探索，Seedance 偏可控生产力 & 实时可交互视频生成。

返回研究成果摘录

架构差异

  • Vidu Q3：U-ViT（All as words 统一序列）+ 长跳连接维持时空一致性。TurboDiffusion 将单张 RTX 5090 上 1080p 生成从 900 秒压缩到 8 秒。
  • Seedance 2.0：MMDiT 双分支 + 时空解耦 + MoE 稀疏化 + 推理阶段 Refiner Model。最多 12 份多模态素材组合输入。

关键指标

  • Vidu 支持 1–16 秒 1080p；Seedance 支持 4–15 秒，最高 2K。
  • 价格：Vidu 标准版每秒约 1.92 元；Seedance 基础版每秒约 0.3 元，字节价格优势明显。
  • 生数 2025 年用户和收入超 10 倍增长，覆盖影视 90%+ 内容方（索尼、腾讯动漫、阅文等）。

未来分化方向

  • Vidu 需"拆链"：拆除长跳连接拐杖，转向原生时空一致性建模，向 3D 影视级视频发展。
  • Seedance 需"减负"：扁平化架构降低通信开销，支撑实时交互速度，向实时交互 3D（AR/VR 接口）发展。

商业化判断

Seedance 更适合需要确定性、分镜控制和与现有短视频工作流集成的创作者和 B/Pro-C 用户，依托字节生态（即梦、剪映、抖音）C 端渗透率高。Vidu 在高溢价创意用例、海外 B 端扩展，以及需要物理真实感、原生视觉动态或未来世界模型邻接性的路径上可能有更大差异化，覆盖影视 90%+ 内容方（索尼、腾讯动漫、阅文等），B 端优势突出。
